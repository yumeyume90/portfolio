# yumeno search

木本夢乃の応募用ポートフォリオです。「業務　困りごと　相談」で検索すると、本人と実績3件が見つかる検索エンジン風のサイトです。実在の検索サービスではありません。

- `index.html` / `style.css` / `main.js`：サイト本体（GitHub Pagesで公開）
- `img/`：本人写真と実績のサムネイル
- `gas/Code.gs`：相談フォームの受け口（Google Apps Script）

## 相談フォームの仕組み

ページ → Google Apps Script → 本人のGmailに通知＋スプレッドシートに記録。

- 通知先のメールアドレスは、ページにもコードにも書いていません（GASを動かすアカウント本人に届きます）
- 見えない入力欄と送信までの時間で、ボットの送信を捨てます
- 1時間あたりの受付数に上限があります（全体20件・同じアドレス3件）
- 入力内容はサーバー側でも検査し、通知はテキストのメールで送ります
- ページには Content-Security-Policy を設定し、通信先を Google Apps Script に限っています
